# Обзор проекта

**marvindocs** — локальный сервис документации для ИИ-ассистентов и
разработчиков, аналог Context7.

## Что делает

Берёт официальную документацию популярных языков, фреймворков и библиотек
(Go, React, PostgreSQL, Git, Python и сотни других), складывает её в одну
базу на твоей машине и даёт по ней быстрый поиск.

Главный потребитель — ИИ-агент (Claude Code, Cursor и подобные): вместо
того чтобы «вспоминать» API по памяти и ошибаться, агент спрашивает у
marvindocs и получает актуальный фрагмент реальной документации.

## Связь с DevDocs

Проект вдохновлён [DevDocs](https://devdocs.io/) — открытым браузером
документации для людей — и основан на нём. Большая часть документации
(837 из 892 наборов) берётся из пакетов DevDocs, и все доки хранятся в его
формате. Остальное собирают наши парсеры: стандартная библиотека Go,
go.dev, все версии Laravel, MongoDB Manual, Metasploit.

Что marvindocs добавляет к DevDocs:

- MCP-сервер, чтобы ИИ-агенты пользовались документацией напрямую;
- поиск по тексту страниц, а не только по заголовкам, — по словам и по смыслу;
- ответ фрагментами в Markdown заданного размера вместо целых HTML-страниц;
- одна программа на всё (поиск, MCP, веб-интерфейс) и готовые наборы с
  собранным индексом.

marvindocs не использует код DevDocs и не связан с его авторами.

## Как работает

1. **Загрузка.** Ты выбираешь нужные документации (по умолчанию ~27 самых
   ходовых, можно весь набор). Сервис скачивает их и строит поисковый
   индекс.
2. **Поиск.** Документация режется на небольшие смысловые кусочки с
   «адресом» (документация → страница → раздел). Запрос ищется двумя
   способами одновременно: по словам (точные термины, имена функций) и по
   смыслу (когда вопрос задан по-человечески, например «подождать
   завершения группы горутин»). Результаты объединяются, и выбирается
   наиболее подходящая страница.
3. **Ответ.** Агент получает фрагмент документации нужного размера — ровно
   то место, которое отвечает на вопрос, с указанием, откуда оно взято.

## Как пользоваться

- Как инструмент агента (MCP): агент сам вызывает `get_docs` с темой и
  названием документации.
- Через веб-интерфейс — читать и искать документацию в браузере.
- Через HTTP-запросы для своих скриптов.

## Зачем это нужно

- Всё работает офлайн и локально: никаких внешних сервисов, лимитов и
  утечек кода.
- Один исполняемый файл, без видеокарты; обычный ноутбук справляется.
- Ответы берутся из официальных источников, а не из памяти модели, поэтому
  меньше выдуманных API и устаревших примеров.
- На внутреннем тесте из 96 вопросов нужная страница оказывается первой в
  двух случаях из трёх и среди первых трёх — в 85 %.
