# Web UI

`marvindocs serve --http :3333` поднимает HTTP-сервер, который отдаёт
одновременно MCP-endpoint (`/mcp`) и минимальный браузерный UI для
чтения проиндексированной документации.

Открой `http://localhost:3333/` в любом браузере.

## Маршруты

| Маршрут | Назначение |
|---|---|
| `GET /` | Список всех проиндексированных документов (из коробки — 791). |
| `GET /search?q=...&doc=...` | Полнотекстовый поиск по именам/путям записей. `doc` опционален, сужает выдачу до одного slug'а. |
| `GET /docs/{slug}/` | `index`-страница документа и сайдбар со всеми его записями. |
| `GET /docs/{slug}/{path}` | Отдельная страница. `path` — из `search.path` или `index.json`. |
| `GET /static/app.css` | Таблица стилей (вшита в бинарь). |
| `GET /mcp` | MCP Streamable HTTP (для агентов, не для человека). |
| `GET /healthz` | Проба живости, возвращает `ok`. |

## Рендеринг

- Тело страницы — **сырой HTML-фрагмент** из `db.json` devdocs,
  обёрнутый в тонкую оболочку (топбар, сайдбар, сброс CSS). Никаких
  трансформаций — блоки кода, таблицы и заголовки выглядят как на
  devdocs.io.
- Относительные ссылки внутри страницы (`foo`, `../bar`) разрешаются
  браузером относительно текущего URL
  (`/docs/{slug}/{current-path}`) — а именно там и живут остальные
  страницы того же документа, поэтому внутренняя навигация просто
  работает.
- Внешние ассеты (картинки, скрипты), которые упомянуты в HTML,
  грузятся напрямую с их оригинальных URL'ов. marvindocs ничего не
  проксирует и не кэширует.

## Ограничения

- **Нет аутентификации.** Если публикуешь на публичный адрес — ставь
  reverse-proxy с авторизацией (nginx + basic auth, OAuth-шлюз).
- **Нет JavaScript.** Поиск и навигация — чистый server-side HTML,
  никакого автокомплита и клиентского роутинга.
- **Нет CSS devdocs.** Фрагменты приезжают без оригинального оформления;
  минимальный вид задаёт `internal/web/static/app.css`.
- **Нет переключателя тёмной темы** (пока).

## Файлы

```
internal/web/
├── web.go                  хендлеры + embed.FS
├── templates/
│   ├── layout.html         общий head/foot
│   ├── index.html          список документов
│   ├── search.html         результаты поиска
│   └── page.html           страница дока + сайдбар
└── static/
    └── app.css             минимальная таблица стилей
```

Все шаблоны и CSS вкомпилены в бинарь через `//go:embed`.
