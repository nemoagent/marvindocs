# Web UI

`marvindocs serve --http :3333` (только loopback; для удалённого доступа
`0.0.0.0:3333`) поднимает HTTP-сервер, который отдаёт
одновременно MCP-endpoint (`/mcp`) и минимальный браузерный UI для
чтения проиндексированной документации.

Открой `http://localhost:3333/` в любом браузере.

## Маршруты

| Маршрут | Назначение |
|---|---|
| `GET /` | Список всех проиндексированных документов (количество зависит от синхронизированного дампа). |
| `GET /search?q=...&doc=...` | Поиск по именам/путям записей (не по телу страниц), до 50 результатов. `doc` опционален, сужает выдачу до одного slug'а. |
| `GET /docs/{slug}/` | `index`-страница документа и сайдбар со всеми его записями. |
| `GET /docs/{slug}/{path}` | Отдельная страница. `path` — из `search.path` или `index.json`. |
| `GET /static/...` | Вшитые ассеты (`app.css`, `theme.js`, `app.js`), отдаются с `Cache-Control: public, max-age=86400`. |
| `/mcp` | MCP Streamable HTTP (для агентов, не для человека). Зарегистрирован для всех методов; клиенты в основном используют `POST`. |
| `GET /healthz` | Проба живости, возвращает `ok`. |

`/search` использует тот же поиск по индексу, что и MCP-инструмент
`search`: при пустом `doc` doc-фильтр определяется из запроса
автоматически, популярные документы получают небольшой буст, а
подстрочный fallback дополняет скудную выдачу. Термины запроса расширяются
[синонимами](synonyms.md). При пустом `q`
показывается подсказка вместо результатов.

## Рендеринг

- Тело страницы — **сырой HTML-фрагмент** страницы devdocs (запись `db.zip`),
  обёрнутый в тонкую оболочку (топбар, сайдбар, сброс CSS). Никаких
  трансформаций — блоки кода, таблицы и заголовки выглядят как на
  devdocs.io.
- Относительные ссылки внутри страницы (`foo`, `../bar`) разрешаются
  браузером относительно текущего URL
  (`/docs/{slug}/{current-path}`) — а именно там и живут остальные
  страницы того же документа, поэтому внутренняя навигация просто
  работает.
- Страницы документов отдаются со strong `ETag` и
  `Cache-Control: public, max-age=300`; при совпавшем `If-None-Match`
  возвращается `304 Not Modified`. Неизвестный slug или страница —
  `404`.
- Внешние картинки, упомянутые в HTML, грузятся напрямую с их
  оригинальных URL'ов (только `https:`). marvindocs ничего не проксирует
  и не кэширует.
- Каждый ответ несёт защитные заголовки: `Content-Security-Policy`,
  который разрешает скрипты только с того же origin (без inline),
  inline-стили, картинки с того же origin и `https:`/`data:`, и запрещает
  встраивание во фреймы (`frame-ancestors 'none'`); плюс
  `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY` и
  `Referrer-Policy: no-referrer`. Поэтому `<script>` или обработчик `on*=`,
  просочившийся в дамп devdocs, не выполняется; внешние скрипты, iframe и
  шрифты внутри страниц документов тоже блокируются.

## Ограничения

- **Аутентификация — только Bearer-токен.** На loopback сервер работает
  без auth; любой другой адрес `--http` требует `--auth-token` (или
  `MARVINDOCS_AUTH_TOKEN`), если не передан `--insecure` (или `MARVINDOCS_INSECURE=1`), и тогда каждый
  запрос, кроме `/healthz`, должен нести `Authorization: Bearer <token>`.
  Если публикуешь на публичный адрес — дополнительно ставь reverse-proxy
  с TLS и/или авторизацией (nginx + basic auth, OAuth-шлюз).
- **Минимум JavaScript.** Поиск и навигация — server-side HTML; из
  скриптов только `/static/theme.js` (применяет тему до первой отрисовки)
  и `/static/app.js` (сам переключатель). Никакого автокомплита и
  клиентского роутинга.
- **Нет CSS devdocs.** Фрагменты приезжают без оригинального оформления;
  минимальный вид задаёт `internal/web/static/app.css`.
- **Тема.** Переключатель светлой/тёмной темы в топбаре сохраняет выбор
  в `localStorage`; без сохранённого выбора используется
  `prefers-color-scheme` браузера.

## Файлы

```
internal/web/
├── web.go                  хендлеры + embed.FS
├── gzip.go                 gzip-сжатие ответов
├── log.go                  middleware access-лога
├── templates/
│   ├── layout.html         общий head/foot
│   ├── index.html          список документов
│   ├── search.html         результаты поиска
│   └── page.html           страница дока + сайдбар
└── static/
    ├── app.css             минимальная таблица стилей
    ├── theme.js            применяет сохранённую тему до первой отрисовки
    └── app.js              переключатель темы
```

Все шаблоны и CSS вкомпилены в бинарь через `//go:embed`.
