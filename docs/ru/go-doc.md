# Документация Go через Docker

Если не хочется ставить локально разные версии Go, используйте `go doc` внутри контейнера.
Так вы получаете документацию из выбранной версии образа и не держите toolchain на хосте.

## Быстрый старт

```bash
# Показать документацию пакета
./scripts/go-doc.sh fmt

# Показать документацию символа
./scripts/go-doc.sh io.Reader

# Все экспортируемые элементы пакета
./scripts/go-doc.sh -all net/http
```

По умолчанию используется образ `golang:1.25`.

## Выбор версии Go

```bash
GO_IMAGE=golang:1.24 ./scripts/go-doc.sh slices
GO_IMAGE=golang:1.23 ./scripts/go-doc.sh maps
```

## Как это устроено

- В `docker-compose.yml` добавлен сервис `godoc`.
- Сервис запускает `go doc` как entrypoint.
- Скрипт `scripts/go-doc.sh` проксирует аргументы в `docker compose run --rm godoc ...`.

## Примечания

- Ничего дополнительно ставить на хост не нужно, кроме Docker.
- Для первого запуска конкретного `GO_IMAGE` Docker скачает образ.
- Документация соответствует версии Go внутри выбранного образа.
